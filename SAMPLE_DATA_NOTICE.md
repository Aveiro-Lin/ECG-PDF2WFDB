# Example-data notice

The `sample/` directory contains a small de-identified subset of an externally
distributed clinical ECG release. It is included only to exercise WFDB loading,
mask handling and TRACE-array plumbing.

The example records retain the source release's data licence and attribution
requirements. The authoritative source record controls provenance, governance,
versioning and permitted reuse. The generic toolkit does not assert ownership of
the underlying clinical data.

The sample identifiers are remapped opaque identifiers. They must not be used to
link the examples back to a source release or to infer patient identity.
